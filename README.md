# Logic Team

## Project Title
Club Hub Web Application

## Overview
This project is a web application built using Django that allows users to create, manage, and view projects. It includes user authentication, project ownership, and basic CRUD operations.

## Features
- User registration and login
- Create, edit, and delete projects
- Project ownership (users can only manage their own projects)
- Authentication-protected routes
- Clean UI for project listing and details

## Tech Stack
- Backend: Django (Python)
- Frontend: HTML, CSS
- Database: SQLite 

## Usage
- Register or log in
- Create a new project
- View and manage your projects
- Edit or delete projects as needed
